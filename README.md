# Нейросетевой синтез дифракционных оптических элементов

Четыре целевых изображения совместно поступают в одну нейросеть, которая
создаёт один фазовый ДОЭ. Из сохранённой маски рассчитываются четыре
восстановления Френеля. Сравниваются амплитуды с независимой нормировкой
каждого изображения по максимуму. Основная метрика — SSIM, дополнительная — Pearson.

## Сборка и запуск в Docker

Нужен работающий Docker с Linux-контейнерами. Python и библиотеки на компьютере
устанавливать не требуется. Образ содержит CPU-версию PyTorch и обученные веса;
GPU не требуется. Интернет используется при сборке, запуск возможен без сети.
Выполняйте команды из корня проекта (PowerShell или Bash).

```sh
docker build -t doe-synthesis .
docker run --rm --network none -v "${PWD}/output:/output" doe-synthesis --sets /app/examples/sets --output /output/five_sets
```

Вторая команда обрабатывает пять включённых комплектов — 20 фрагментов
реальных фотографий из отложенной выборки DIV2K. Происхождение изображений
записано в `examples/sources.json`. В каждом комплекте четыре разных исходника.
При повторном запуске укажите новое имя выходной папки, например `five_sets_02`.

Для своих четырёх PNG положите их в папку `input` и выполните:

```sh
docker run --rm --network none -v "${PWD}/input:/input:ro" -v "${PWD}/output:/output" doe-synthesis --targets /input/1.png /input/2.png /input/3.png /input/4.png --output /output/my_set
```

Порядок изображений соответствует глубинам **24,1 / 25,3 / 26,5 / 27,7 мм**.
Вход: PNG 128×128, 8 бит, Grayscale. Для нескольких комплектов создайте
подпапки `input/set_01`, `input/set_02` и т. д., по четыре PNG в каждой,
с именами `1.png`, `2.png`, `3.png`, `4.png`, и замените аргумент `--targets ...`
на `--sets /input`. Внутри комплекта файлы сортируются по имени.

Выход одного комплекта:

- `doe.png` — **128×128, 8 бит, Grayscale**, один канал без альфа-канала.
  Значения 0…255 кодируют фазу от −π до +π.
- `reconstruction/` — четыре восстановленных изображения и `metrics.json`.
- `summary.json` — SSIM, Pearson и время синтеза. При `--sets` этот отчёт
  общий, а маски и восстановления расположены в подпапках комплектов.

Метрики сначала усредняются по четырём плоскостям каждого комплекта,
затем — по всем комплектам с равным весом. Оценивается именно сохранённая
8-битная маска. `synthesis_ms` включает расчёт сети и перевод фазы в 8-битный
массив, без чтения входных файлов и оценки качества; первый вызов не исключается.
Загрузка модели измеряется отдельно (`model_load_ms`). `total_seconds` включает
подготовку, синтез, запись PNG и проверку качества, но не старт Python и импорт библиотек.

Сборка автоматически запускает все тесты, включая обработку пяти комплектов,
проверку заголовков PNG и двухступенчатого усреднения метрик.
Повторная проверка внутри готового образа:

```sh
docker run --rm --network none --entrypoint python doe-synthesis -m unittest discover -s tests -v
```

## Модель и метрики

- Падающая волна плоская, амплитуда единичная. Длина волны 532 нм, шаг пикселя
  маски 10 мкм. На каждой глубине применяется формула Френеля с одним
  центрированным FFT. Шаг выходной сетки равен λz/(N·Δu), где N = 128 и Δu
  — шаг пикселя маски. Изображения сравниваются попиксельно на этой сетке.
- Исходное изображение трактуется как целевая амплитуда. Восстановление — модуль
  комплексного поля. Каждое изображение делится на собственный максимум.
  Полностью чёрное изображение остаётся нулевым. Метрики вычисляются
  до округления восстановленной амплитуды для экспорта в PNG.
- КК Пирсона вычисляется по всем пикселям. Для пары с константным изображением
  КК не определён и сохраняется как `null`.
- [SSIM по Wang и соавторам](https://ece.uwaterloo.ca/~z70wang/publications/ssim.pdf)
  использует гауссово окно 11×11 с σ = 1,5, диапазон [0, 1], K1 = 0,01,
  K2 = 0,03 и взвешенные дисперсии и ковариацию. Усредняются значения в окнах,
  полностью лежащих внутри изображения.

## Данные для обучения

В `data/div2k` находятся подготовленные изображения DIV2K и списки четвёрок.
Каждый PNG имеет размер 128×128 и один 8-битный канал. В каждой четвёрке
четыре разные исходные фотографии. Порядок путей соответствует расстояниям
24,1 / 25,3 / 26,5 / 27,7 мм.

| Выборка | Исходные фотографии | Фрагменты | Четвёрки |
| --- | ---: | ---: | ---: |
| Обучение | 700 | 11 200 | 20 000 |
| Валидация | 100 | 1 600 | 400 |
| Тест | 100 | 1 600 | 400 |

Из официальных 800 обучающих фотографий 100 выделены для валидации.
Официальные 100 валидационных фотографий используются как отложенный тест
этого проекта. Разбиение выполнено до нарезки с seed 42. Все фрагменты одного
исходника принадлежат одной выборке. Каждому фрагменту соответствует хотя бы
одна четвёрка. Обучающие четвёрки переиспользуют фрагменты в разных сочетаниях.

Первый кандидат каждого исходника — центральный квадрат, остальные — случайные
квадраты со стороной от 35% до 100% короткой стороны фотографии. Фрагменты
переводятся в оттенки серого и уменьшаются методом Lanczos.
В обучение добавлены случайные отражения и повороты на кратные 90° углы.
Для отбора содержательных фрагментов стандартное отклонение яркости должно
быть не меньше 0,05, а средний модуль разности соседних пикселей — не меньше
0,01 в диапазоне [0, 1]. Этот фильтр отбрасывает почти однородные участки.

Файлы `train.jsonl`, `validation.jsonl` и `test.jsonl` содержат по одной
четвёрке в строке. Пути отсчитываются от `data/div2k`. В `sources.jsonl`
записаны исходники и их SHA-256, в `crops.jsonl` — координаты нарезки,
преобразования и контрольные суммы пикселей. Параметры подготовки находятся
в `metadata.json`.

В `preview.png` показаны примеры четвёрок из каждой выборки.
В `validation_report.json` сохранены результаты полной проверки подготовленного
набора, включая формат PNG, контрольные суммы, раздельность исходников
и использование всех фрагментов в четвёрках.

Чтение одной четвёрки для будущей нейросети выполняется так.

```python
import json
from pathlib import Path
from dataset import load_quadruplet

root = Path("data/div2k")
with (root / "train.jsonl").open(encoding="utf-8") as source:
    sample = json.loads(next(source))
amplitudes = load_quadruplet(root, sample)
assert amplitudes.shape == (4, 128, 128)
```

Загрузчик делит каждое изображение на собственный максимум и возвращает
массив `float32`.

Для воспроизведения подготовки используйте следующие команды. Архивы
сохраняются в `data/raw`, загрузка после обрыва продолжается с сохранённого

DIV2K предоставлен для академических исследований, права на изображения
принадлежат их владельцам. Условия и архивы опубликованы на

При использовании набора авторы просят ссылаться на следующие работы.

  Methods and Results. CVPR Workshops, 2017.

## Нейросетевой синтез

`model.py` содержит компактную U-Net. На вход подаются четыре нормированные
амплитуды. Фиксированный слой обратного распространения Френеля переводит их
в четыре комплексных поля в плоскости ДОЭ. U-Net получает действительные и
мнимые части этих полей и рассчитывает поправку к их среднему. Аргумент
результирующего поля задаёт фазу единственной маски в пределах [−π, π].
Начальные фазы целевых полей фиксированы, поэтому результат модели
воспроизводим при повторном запуске.

Далее внутри сети выполняются шесть шагов согласования амплитуд на четырёх
глубинах. Каждый шаг распространяет поле вперёд, приближает амплитуды к целевым
и объединяет обратно распространённые поля в одну фазовую маску.
Сила каждого шага обучается совместно с U-Net. Это фиксированная развёрнутая
архитектура с дифференцируемыми оптическими слоями. Число шагов задаётся
параметром `--refinement-steps`.

Обучение использует все четыре плоскости одновременно. Функция ошибки равна
`MSE + 0.5 × (1 − SSIM) + 0.25 × (1 − КК) + 2 × штраф смешения`,
с равным вкладом каждой глубины. Штраф смешения требует, чтобы восстановление
сильнее коррелировало со своей целью, чем с тремя чужими. Требуемый запас равен
`0.25 × (1 − КК между соответствующими целевыми изображениями)`.
Для одинаковых целей этот запас равен нулю.
В отчёте дополнительно сохраняется доля восстановлений, для которых максимальная
корреляция достигается именно со своей целевой картинкой.
Фаза округляется до 256 уровней при обучении и валидации. Для прохождения
градиента через округление используется straight-through estimator.
Параметры SSIM совпадают с проверкой на NumPy.

Для NVIDIA с поддержкой CUDA 12.8 окружение устанавливается так.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r requirements-training.txt
```

Варианты установки для других устройств приведены в
[официальной инструкции PyTorch](https://pytorch.org/get-started/locally/).

Обучение и продолжение сохранённого запуска выполняются следующими командами.
Путь вывода нового запуска должен быть свободным.

```powershell
.\.venv\Scripts\python.exe train.py --epochs 20 --batch-size 32 --output runs/new_training
.\.venv\Scripts\python.exe train.py --epochs 30 --batch-size 32 --output runs/new_training --resume
```

Каждая эпоха проходит 20 000 обучающих четвёрок. Для выбора модели используется
ошибка на 400 валидационных четвёрках после округления фазы. Все изображения
загружаются в оперативную память один раз, чтобы обучение не зависело от
скорости повторного чтения PNG.

В папке запуска сохраняются `best.pt` и `last.pt`, исходная оценка
`initial_validation.json`, лучшая оценка `best_validation.json`,
журнал `history.jsonl` и параметры `config.json`. Контрольные точки содержат
состояние оптимизатора, номер эпохи и состояния генераторов случайных чисел.
При продолжении проверяется соответствие списков обучающих данных.

Готовая модель применяется к четырём PNG так.

```powershell
.\.venv\Scripts\python.exe synthesize.py --targets target_1.png target_2.png target_3.png target_4.png --output results/neural_example
```

Результат содержит `doe.png` и папку `reconstruction` с восстановленными
изображениями и метриками. Восстановление выполняется проверенным симулятором
NumPy из сохранённого PNG маски.

Все проверки, включая согласованность двух симуляторов и проверку градиентов,
запускаются в окружении с PyTorch.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Сравнение с классическим методом

`baselines.py` реализует многоплоскостной алгоритм Герчберга–Сэкстона.
На каждой итерации он задаёт целевые амплитуды на четырёх глубинах, распространяет
поля обратно и выделяет фазу среднего комплексного поля. При старте используется
обратное распространение целей с фиксированными случайными фазами и seed 42.

Одна команда сравнивает четыре режима на всех 400 тестовых четвёрках.

```powershell
.\.venv\Scripts\python.exe benchmark.py --checkpoint weights/model.pt --output runs/benchmark_new
```

Режимы включают GS на 10 и 100 итераций, полный вызов обученной сети с шестью
встроенными оптическими шагами, а также сеть с десятью дополнительными
итерациями GS. Все методы исполняются на одном устройстве в float32.
Измеряется синтез одной маски за вызов, включая перевод в 8-битный массив.
Перед замерами выполняется прогрев. После каждого расчёта GPU синхронизируется.
Модель и входные изображения загружаются заранее. Для каждой четвёрки
выполняются три измерения каждого метода с чередованием порядка.

Качество оценивается после сохранения и повторного чтения каждой фазовой маски.
В папке сравнения находятся `summary.json`, `per_plane.csv`, `samples.jsonl`,
маски всех вариантов в `masks`, визуальное сравнение `comparison.png`
и описание методики в `report.md`. Параметры запуска, версии библиотек
и контрольные суммы записываются в `config.json`.

Классический и гибридный режимы также доступны через обычный синтез.

```powershell
.\.venv\Scripts\python.exe synthesize.py --method gs --gs-iterations 100 --targets target_1.png target_2.png target_3.png target_4.png --output results/classical
.\.venv\Scripts\python.exe synthesize.py --method hybrid --refine-iterations 10 --targets target_1.png target_2.png target_3.png target_4.png --output results/hybrid
```

Выполненное сравнение сохранено в `runs/benchmark`. Результаты для RTX 5060
Laptop GPU на 400 тестовых четвёрках приведены ниже. Время — медиана расчёта
одной маски из четырёх изображений после прогрева.

| Метод | Средний КК | Средний SSIM | Время, мс |
| --- | ---: | ---: | ---: |
| GS, 10 итераций | 0,4218 | 0,2502 | 7,61 |
| GS, 100 итераций | 0,5183 | 0,3435 | 68,06 |
| Нейросеть | 0,4449 | 0,2733 | 8,40 |
| Нейросеть и 10 дополнительных итераций GS | 0,4735 | 0,2986 | 15,31 |

В этом запуске сеть примерно в 8,1 раза быстрее GS на 100 итераций и уступает
ему по качеству. Короткий GS на 10 итераций имеет меньшую медиану времени
и уступает сети по обоим показателям сходства. Дополнительные 10 итераций
улучшают результат сети при увеличении времени расчёта.

Во всех четырёх вариантах остаётся выраженный зернистый шум. Подробные
распределения времени, оценки каждой глубины, все 1 600 масок и пример
восстановлений доступны в папке сравнения.
